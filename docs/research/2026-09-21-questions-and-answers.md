## How to read this

- **Confirmed — Can:** direct answer in this conversation.
- **Recorded decision:** an existing project decision, not an invitation to re-decide it.
- **Board note / partial:** reported content from Miro; author, date, representativeness, and final approval are unverified. A related note is not necessarily an answer to the original question.
- **Open:** no answer found in the reviewed material. It may exist elsewhere.
- **Deferred:** deliberately later; not a blocker for the current slice.
- **Verify:** a file, professional answer, live configuration, or test is needed; Can should not have to guess.

Use **D01–D24** to answer the founder/product questions. Use **E01–E12** to collect external or technical evidence. **P01–P28** preserve the original planning numbers. **B01–B59** preserve the board questions and reported answers.
